# Preguntas abiertas y decisiones pendientes

## Pendientes funcionales: ninguno

Las reglas de negocio, duraciones, límites, responsables, condiciones de aceptación y casos borde del alcance acordado están definidos en `spec.md`. No hay reglas con números faltantes que deban inventarse durante la implementación.

## Gestiones externas al código, pendientes antes de entregar en el aula

| Prioridad | Pregunta o actividad externa | Impacto | Responsable |
|---|---|---|---|
| Alta | ¿Cuál es la URL del repositorio público de GitHub? | El aula exige el enlace al repo. Se crea al subir este proyecto a la cuenta del alumno. | Alumno |
| Alta | ¿Cuál es la URL pública de la aplicación? | La docente necesita abrirla y probarla sin instalar nada. Se obtiene al publicar. | Alumno |
| Alta | ¿Dónde se guardará la base de datos de forma persistente en el despliegue? | El almacenamiento local gratuito de Render es efímero. Para uso permanente debe contratarse disco persistente o migrarse a una base gestionada. | Alumno |

Estas actividades **no** implican indefinición de las reglas del negocio. Se registran para no confundir un desarrollo local terminado con un despliegue público efectivamente realizado.
